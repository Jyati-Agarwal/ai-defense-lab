# AI Defense Lab completion audit

**Verdict: NOT COMPLETE against the original Sections 1–6 and backend Definition of Done.** The repository contains a substantial, real, hash-bound implementation, but its own artifacts disprove full entity-behavior fidelity and a pristine held-out-family claim. The active release is a **fresh-row post-remediation regression**, not the originally requested unseen-family evaluation.

## Highest-priority completion gaps

1. **Behavioral fidelity fails.** `results/fidelity.json:5-18,41-44` passes at AUC `0.5133847`, but explicitly measures only amount plus an elapsed-hour proxy and disclaims behavioral/entity-state fidelity. The entity-level result is `STOP_FAIL`: `D=0.8642926`, 95% CI `[0.8519410,0.8801393]`, ceiling `0.65` (`results/entity_fidelity_mrs2_development.json:462-468,670-687`).
2. **D is not a pristine held-out-family test.** `results/generalization.json:13-18` says `independent_holdout=false`, `pristine_heldout_family=false`, and prior families were disclosed. A post-evaluation amendment withdrew the original ordering gates (`results/evaluation_v4_release_policy_amendment.json:17-19,42-45`).
3. **The headline is not the lowest result.** Known/adaptive/novel/D recall is `1.0/1.0/0.84782609/1.0`, yet D remains the headline and `expected_order_holds=false` (`results/generalization.json:2-8`).
4. **The shuffle gate is narrower than specified.** It retrains the learned stack 50 times, but zeros deterministic/direct priors and certifies only temporal-A rows having text; C/D/E are excluded (`defend/evaluate.py:468-477,580-650`; `results/generalization.json:136-205`). The whole-defense, whole-temporal-holdout claim is therefore not established.
5. **Current test evidence is inconsistent.** `tests/test_evaluation.py:81` requires the V1 diagnostic status to be `FAIL`; the current artifact records `PASS` (`results/generalization.json:148`). No current test-run receipt exists, and the design-jury artifact has `gate_passed=false` for all 12 screens.
6. **SHAP is layer-local, not the specified global top three.** The implementation chooses one dominant non-structural layer and ranks SHAP values only inside it; a deterministic floor can displace a SHAP reason (`defend/models/bundle.py:111-154`).
7. **No measured `/compose` endpoint p99 is stored.** The only persisted p99 is `11.052963 ms` for warmed, feature-ready A+B model scoring and explicitly says HTTP was measured separately (`results/metrics.json:68-71`).
8. **Vaccination rejected safely but did not complete promotion.** The candidate improved the survivor stop rate, then raised E stop rate to `0.202` and Brier to `0.34344765`; it was rejected, with no candidate/promoted artifact (`results/vaccination.json:9,24-47,67-69`).
9. **Fresh-clone reproducibility and repository hygiene are incomplete.** Git has no `HEAD`; every project file is untracked. `make all` omits setup, LLM-cache preparation, and the one-time preregistration it requires (`Makefile:117-133`; `README.md:37-51`). Two raw diagnostic-cache files expose `request_envelope`/`response` fields and are allowlisted by `.gitignore:16-18`; their values were not inspected.
