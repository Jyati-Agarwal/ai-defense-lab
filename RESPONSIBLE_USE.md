# Responsible use

AI Defense Lab is a defensive research demonstrator for payment-security evaluation.

- Every person, account, device, merchant, beneficiary, trace, and transaction is synthetic.
- Attack examples are truncated and watermarked. They demonstrate observable artifacts, not deployable phishing, impersonation, malware, cloning, or probing techniques.
- The project never targets a live payment system and never uses production credentials or personal data.
- Red-generated traffic cannot update the deployed model directly. Vaccines must pass regression, benign-traffic, and calibration gates before promotion.
- Results measure this simulator and frozen evaluation protocol. They are not claims about a bank, network, issuer, merchant, or population outside the documented experiment.

Use the code only in systems you own or are explicitly authorized to test. Keep all evaluation isolated from real customers and real funds.
